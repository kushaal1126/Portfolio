02 / PROJECTS

MULTIDISCIPLINARY IOT PROJECT

ATM Jackpotting Defense System

ATM jackpotting is a type of attack in which criminals attempt to force an ATM to dispense cash without an authorized transaction. This project explores a layered defensive approach to reducing the risk of unauthorized cash-dispensing commands.

My Role

As the Threat Modeler and Security Compliance Lead, my responsibilities include researching ATM jackpotting attack scenarios, examining relevant security weaknesses, and contributing to the design of defensive controls.

Defensive Approach

  • Step 1 — Application Allowlisting: Develop a Python-based simulation that checks files against approved hashes and identifies unapproved applications.
  • Step 2 — Command Authorization: Explore a controlled model in which cash-dispensing commands require authorization rather than being accepted solely because they originate locally.
  • Step 3 — Intrusion Detection: Explore defensive monitoring for suspicious network activity and unusual behavior.

Learning Objectives

The project aims to demonstrate how application control, command authorization, and intrusion monitoring can work together as layers of defense. It also provides an opportunity to apply Python programming and threat-modeling concepts to an IoT security scenario.

Python Cybersecurity IoT Security Threat Modeling Application Allowlisting

Project status: In progress. Implementation details and results will be added as the project develops.
